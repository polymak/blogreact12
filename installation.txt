INSTALLATION DE BLOGREACT - CLOUDFLARE PAGES & WORKERS
======================================================

ARCHITECTURE MODERNE SERVERLESS
-------------------------------
BlogReact a été refacturé pour une architecture moderne sans serveur utilisant Cloudflare Pages et Cloudflare Workers.

Nouvelle structure :
BlogReact12/
├── frontend/                 # Cloudflare Pages (Frontend statique)
│   ├── index.html
│   ├── login.html
│   ├── dashboard.html
│   ├── article.html
│   ├── script.js
│   ├── style.css
│   └── _redirects
├── worker/                   # Cloudflare Worker API
│   ├── worker.js
│   ├── wrangler.toml
│   └── package.json
├── database/
│   └── db.js
└── uploads/                  # Future Cloudflare R2 storage

INSTALLATION ÉTAPE PAR ÉTAPE
----------------------------

1. CLONER OU TÉLÉCHARGER LE PROJET
   - Téléchargez les fichiers du projet dans un dossier de votre choix
   - Structure attendue :
     BlogReact12/
     ├── frontend/
     ├── worker/
     ├── database/
     └── installation.txt

2. CONFIGURER LA BASE DE DONNÉES
   - Ouvrez MySQL Workbench ou votre client MySQL préféré
   - Créez une nouvelle base de données : blogreact12
   - Exécutez le script : database/schema.sql
   - Cela créera les tables et insérera les données de test

3. INSTALLER LES DÉPENDANCES WORKER
   - Ouvrez un terminal dans le dossier worker/
   - Exécutez : npm install
   - Cela installera wrangler et mysql2

4. CONFIGURER LE WORKER CLOUDFLARE
   - Ouvrez worker/wrangler.toml
   - Configurez votre compte Cloudflare :
     - name = "votre-nom-worker"
     - account_id = "votre-account-id"
   - Configurez la base de données :
     - [[d1_databases]] pour Cloudflare D1 (recommandé)
     - Ou [[vars]] pour MySQL externe

5. DÉPLOYER LE WORKER
   - Connectez-vous à Cloudflare : wrangler login
   - Déployez le Worker : wrangler publish
   - Notez l'URL du Worker (ex: votre-worker.workers.dev)

6. DÉPLOYER LE FRONTEND SUR CLOUDFLARE PAGES
   - Connectez votre repo GitHub à Cloudflare Pages
   - Configurez les paramètres :
     - Build command: echo "No build needed"
     - Build directory: frontend
   - Déployez

7. CONFIGURER LES VARIABLES D'ENVIRONNEMENT
   - Pour MySQL externe :
     wrangler secret put DB_HOST
     wrangler secret put DB_USER
     wrangler secret put DB_PASSWORD
     wrangler secret put DB_NAME

8. ACCÉDER À L'APPLICATION
   - Frontend : https://blogreact12.pages.dev
   - API : https://blogreact12-api.reatest.workers.dev/api
   - Page de connexion : https://blogreact12.pages.dev/login

9. ESPACE ADMINISTRATION
   - Page de connexion : /login (sur votre domaine Pages)
   - Identifiants par défaut :
     - Admin : username: Admin, password: Admin
     - Editor : username: editor, password: editor

FONCTIONNALITÉS DISPONIBLES
---------------------------
✓ Frontend statique sur Cloudflare Pages
✓ API serverless via Cloudflare Worker
✓ Clean URLs avec _redirects
✓ CORS configuré pour les requêtes cross-origin
✓ Base de données MySQL externe ou Cloudflare D1
✓ Images prêtes pour Cloudflare R2

TROUBLES COURANTS
-----------------
- Erreur de connexion MySQL : Vérifiez que MySQL est démarré et que les identifiants sont corrects
- Worker ne répond pas : Vérifiez le déploiement et les variables d'environnement
- Frontend ne charge pas : Vérifiez que le build directory est "frontend"
