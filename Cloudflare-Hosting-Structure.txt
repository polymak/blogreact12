DOCUMENTATION POUR DÉPLOIEMENT CLOUDFLARE

## 🏗️ ARCHITECTURE GLOBALE

```
BlogReact12/
├── frontend/                 # CLOUDFLARE PAGES (Frontend statique)
│   ├── index.html           # Page d'accueil
│   ├── login.html           # Page de connexion
│   ├── dashboard.html       # Tableau de bord admin
│   ├── article.html         # Page article dynamique
│   ├── script.js           # Logique frontend (mise à jour)
│   ├── style.css           # Styles CSS
│   └── _redirects          # Configuration routing Pages
├── worker/                 # CLOUDFLARE WORKER (API serverless)
│   ├── worker.js          # Code API endpoints

│   └── package.json       # Dépendances Worker
├── database/              # Base de données
│   └── db.js             # Connexion DB (mock pour Worker)
├── uploads/              # Future R2 storage
└── README.md             # Documentation projet
```

## 📁 STRUCTURE DÉTAILLÉE

### FRONTEND (Cloudflare Pages)
**Répertoire :** `/frontend/`
**Type :** Contenu statique
**Build :** Aucun build nécessaire
**Fichiers :**
- `index.html` - Page d'accueil avec grille d'articles
- `login.html` - Formulaire d'authentification
- `dashboard.html` - Interface administration
- `article.html` - Page article dynamique (query params)
- `script.js` - Logique frontend (fetch API Worker)
- `style.css` - Styles Tailwind CSS
- `_redirects` - Routing clean URLs

### WORKER (Cloudflare Workers)
**Répertoire :** `/worker/`
**Type :** API serverless
**Runtime :** JavaScript/Node.js
**Fichiers :**
- `worker.js` - Code API (export default)
- `wrangler.toml` - Configuration déploiement
- `package.json` - Dépendances (wrangler, mysql2)

### DATABASE
**Répertoire :** `/database/`
**Type :** Connexion base de données
**Fichiers :**
- `db.js` - Mock database pour Worker

## 🌐 CONFIGURATION CLOUDFLARE

### Cloudflare Pages
**Build Settings:**
- Build command: `echo "No build needed"`
- Build directory: `frontend`
- Framework preset: `None`

**Environment Variables:**
- Aucune variable requise pour le frontend

**Custom Domains:**
- Votre domaine Pages (ex: `votre-projet.pages.dev`)

### Cloudflare Workers
**wrangler.toml Configuration:**
```toml
name = "blogreact12-api"
main = "worker.js"
compatibility_date = "2024-01-01"

[env.production]
name = "blogreact12-api-prod"

[env.development]
name = "blogreact12-api-dev"

# Database configuration
[[d1_databases]]
binding = "DB"
database_name = "blogreact12-d1"
database_id = ""

# OR External MySQL
[[vars]]
DB_HOST = ""
DB_USER = ""
DB_PASSWORD = ""
DB_NAME = ""
```

**Environment Variables:**
- `DB_HOST` - Hôte MySQL (si externe)
- `DB_USER` - Utilisateur MySQL
- `DB_PASSWORD` - Mot de passe MySQL
- `DB_NAME` - Nom base de données

## 🔌 ENDPOINTS API WORKER

### Public Endpoints (No Auth)
- `GET /api/articles` - Tous les articles
- `GET /api/articles/:id` - Article par ID
- `GET /api/articles/category/:category` - Articles par catégorie
- `GET /api/articles/author/:author` - Articles par auteur
- `GET /api/articles/recent/:limit` - Articles récents
- `GET /api/categories` - Toutes les catégories
- `GET /api/articles/search` - Recherche d'articles
- `GET /api/stats` - Statistiques blog
- `POST /api/articles/:id/views` - Incrémenter vues
- `POST /api/articles/:id/likes` - Incrémenter likes

### Authenticated Endpoints
- `POST /api/login` - Authentification
- `POST /api/articles` - Créer article
- `PUT /api/articles/:id` - Modifier article
- `DELETE /api/articles/:id` - Supprimer article

## 🚀 DÉPLOIEMENT ÉTAPES

### 1. Préparer la Base de Données
```sql
-- Créer base de données
CREATE DATABASE blogreact12;

-- Exécuter schema.sql
SOURCE database/schema.sql;
```

### 2. Configurer le Worker
```bash
cd worker
npm install
# Modifier wrangler.toml avec vos credentials
```

### 3. Déployer le Worker
```bash
wrangler login
wrangler publish
# Notez l'URL: votre-worker.workers.dev
```

### 4. Déployer le Frontend
```bash
# Connecter repo GitHub à Cloudflare Pages
# Configurer build directory: frontend
# Déployer
```

### 5. Configurer les Variables
```bash
# Pour MySQL externe
wrangler secret put DB_HOST
wrangler secret put DB_USER
wrangler secret put DB_PASSWORD
wrangler secret put DB_NAME
```

## 🔧 CONFIGURATION SUPPLÉMENTAIRE

### CORS Headers
Déjà configurés dans le Worker:
```javascript
'Access-Control-Allow-Origin': '*'
'Access-Control-Allow-Methods': 'GET, POST, PUT, DELETE, OPTIONS'
'Access-Control-Allow-Headers': 'Content-Type, Authorization'
```

### URLs avec Extensions .html
Configuration via `_redirects`:
```
/accueil.html /index.html 200
/login.html /login.html 200
/dashboard.html /dashboard.html 200
/article.html /article.html 200
/* /index.html 200
```

### Image Storage (Future R2)
À configurer dans wrangler.toml:
```toml
[[r2_buckets]]
binding = "IMAGES"
bucket_name = "blogreact12-images"
```

## 🚨 POINTS IMPORTANTS

### Migration Données
- Base de données MySQL existante → Compatible
- Images upload/ → Future migration R2
- Users existants → Conservation

### Limitations Worker
- Temps d'exécution: 1 seconde (CPU time)
- Mémoire: 128MB
- Taille code: 1MB (compressed)

### Best Practices
- ✅ API responses < 4MB
- ✅ Database connections optimisées
- ✅ Error handling robuste
- ✅ Logging approprié
