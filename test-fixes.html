🔄 Comment Tester

Pour vérifier que tout fonctionne correctement :

  1. Démarrer le serveur backend :
    2. cd backend && node worker.js
  2. Ouvrir le dashboard :
    3. frontend/dashboard.html
  3. Tester la publication :
    • Cliquez sur "Ajouter un Article"
    • Remplissez le formulaire et cliquez sur "Publier"
    • Vérifiez que la page se rafraîchit et que le nouvel article apparaît
  4. Tester la modification :
    • Dans la liste des articles, cliquez sur l'icône d'édition
    • Modifiez le contenu et cliquez sur "Publier"
    • Vérifiez que les changements sont enregistrés
